# Your Energy 💪

**Your Energy** — це сучасний веб-застосунок для фітнесу, розроблений для пошуку
вправ, перегляду технік виконання та створення власної програми тренувань.
Проєкт реалізовано як фінальну курсову роботу з дисципліни "JavaScript Web
Development".

Застосунок допомагає користувачам знаходити вправи за групами м'язів, частинами
тіла або обладнанням, надає детальну інформацію про кожну вправу та дозволяє
зберігати улюблені тренування.

## ✨ Ключові можливості

- **Розумний пошук та фільтрація:** Зручна навігація за категоріями: `Muscles`
  (М'язи), `Body parts` (Частини тіла), `Equipment` (Обладнання).
- **Інтерактивні картки:** Перегляд списку вправ з пагінацією.
- **Детальні інструкції:** Модальні вікна з анімованими GIF-демонстраціями,
  описом техніки, рейтингом та інформацією про спалені калорії.
- **Favorites (Улюблене):** Можливість додавати вправи до списку улюблених. Дані
  зберігаються локально, тому ваш список доступний навіть після перезавантаження
  сторінки.
- **Рейтинг та відгуки:** Система оцінювання вправ користувачами.
- **Мотивація:** Блок "Quote of the day" (Цитата дня) для підтримки спортивного
  духу.
- **Адаптивність:** Повністю чуйний дизайн (Responsive Design), що коректно
  працює на мобільних пристроях, планшетах та десктопах.

## 🛠 Технічний стек

Проєкт створено на чистому **Vanilla JavaScript** без використання важких
фреймворків.

- **Core:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+).
- **Збірка:** [Vite](https://vitejs.dev/) — для швидкої розробки та оптимізації.
- **HTTP-запити:** [Axios](https://axios-http.com/) — для взаємодії з backend
  API.
- **UI Компоненти:**
  - [iziToast](https://izitoast.marcelodolza.com/) — для стильних сповіщень.
  - Custom Modals — власна реалізація модальних вікон.
- **Архітектура:** Модульна структура JS, BEM-методологія для CSS (частково).

## 🚀 Інструкція із запуску

Щоб запустити проєкт локально на своєму комп'ютері:

1.  **Клонуйте репозиторій:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/your-energy.git](https://github.com/YOUR_USERNAME/your-energy.git)
    ```
2.  **Перейдіть у папку проєкту:**
    ```bash
    cd your-energy
    ```
3.  **Встановіть залежності:**
    ```bash
    npm install
    ```
4.  **Запустіть режим розробки:**
    ```bash
    npm run dev
    ```
5.  Відкрийте посилання, яке з'явиться в терміналі (зазвичай
    `http://localhost:5173/`).

## 📂 Структура проєкту

```text
src/
├── css/            # Стилі (розбиті на компоненти та лейаути)
├── img/            # Оптимізовані зображення та SVG-спрайт
├── js/             # Логіка застосунку
│   ├── api/        # API сервіси (запити до серверу)
│   ├── components/ # Функції рендеру HTML
│   ├── handlers/   # Обробники подій (handlers)
│   └── listeners/  # Слухачі подій
├── partials/       # HTML-фрагменти (Header, Hero, Footer, Modals)
└── index.html      # Головна точка входу
```
